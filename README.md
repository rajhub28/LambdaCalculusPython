# Lambda Calculus in Python

LC.py contains a list of lambda expressions in Python that implement Church's Lambda Calculus. The following are implemented:

- Boolean type and operators
- Number type (0, 1, ...) and operations on numbers
- Pair and List data structure and associated operators
- Signed numbers (...,-3, -2, -1, 0, 1, 2, 3, ...) and some operations
- Char data type, isLower, isUpper, isDigit, toLower, toUpper
- String data type as a list of Char data

Some String functions implemented are: 

- strlen
- strcat
- join
- is_prefix, is_suffix
- find substring in string, return index as signed number
- extract prefix, suffix of strings at an index
- extract substring given left and right indices

Some numeric functions implemented are:

- factorial of a number
- fibonacci number

Some list functions implemented are:

- sum a list of numbers
- find the length of a list of numbers
- return two consecutive copies of each element of a list
- find the largest number in a list of numbers
- quicksort a list of numbers
- mergesort a list of numbers
- test if two lists of numbers are disjoint
- test if a list of numbers is ordered (sorted)
- generate subsets of a list of numbers
- union, intersect, difference of two lists of numbers

Higher order functions: 

- map
- filter
- foldr
- foldl
- twice, thrice

Additional functions are being added as and when time permits!
